How it works

3 steps
01

Connect a wallet

No sign-up, no password. Your account is created automatically and your personal API key appears on the dashboard.

lode_8f3a2c…e91d
02

Install & log in

Install the CLI (requires Node.js 18+), then log in with that API key.

npm install -g lode-cli lode login <API_KEY>
03

Mine

Run one command. Every CPU core gets to work. When each one-minute round ends, its LODE is split between the miners by work done.

lode mine
Note

The server hands out a random challenge, the CLI searches for a nonce until the SHA-256 hash has enough leading zero bits, and the server verifies it with a single hash. Difficulty adjusts per miner so everyone finds about one share every 20 seconds, and each share counts for the work it took. Emission per round is fixed and halves every 30 days, so extra machines or bots can't print more LODE, only compete for the same amount. See the economy →
